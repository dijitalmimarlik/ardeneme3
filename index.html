Kontroller (AR içinde)
Kumandayla:
• Thumbstick ileri/geri = zoom (ileri = yakınlaş, geri = uzaklaş)
• Thumbstick sağ/sol = gözlemci modelin etrafında sağa/sola gider
• Thumbstick'e bas = modeli anında sıfırla
• Tetik (basılı tut) = modeli fare gibi sürükleyerek çevir
• Grip (basılı tut) = modeli her eksende taşı
• A veya B (sol kumandada X veya Y) basılı tut = yatay dönüş (yön) korunur, diğer eksenler yavaşça ilk haline döner
Elle (hand tracking, pinch = baş + işaret parmağı):
• Sağ el pinch (basılı tut) = modeli fare gibi sürükleyerek çevir
• Sol el pinch (basılı tut) = modeli taşı
• İki el birden pinch = zoom (elleri aç/kapat)
